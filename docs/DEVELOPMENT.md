# 개발 기록

핑계생성기를 만들면서 무엇을 어떤 순서로 했고, 어디서 막혔고, 어떻게 고쳤는지 기록합니다. 개별 결정의 한 줄 요약은 [DECISIONS.md](../DECISIONS.md), 요구사항은 [PRD.md](../PRD.md)에 있습니다.

## 진행 방식

- PRD에 마일스톤(M1~M7)과 완료 기준을 먼저 정하고, 한 단계씩 구현했다
- 단계가 끝날 때마다 커밋하고 멈춘 뒤, **실제 폰에서 완료 기준을 확인한 다음에만** 다음 단계로 넘어갔다
- PRD에 없는 기능은 넣지 않고, 애매한 부분은 가장 단순한 방법을 고른 뒤 DECISIONS.md에 한 줄로 남겼다
- 프롬프트는 "샘플을 뽑아 사람이 직접 읽고 → 문제를 수치로 세고 → 고치고 → 다시 뽑기"를 반복했다

## 프롬프트 튜닝 기록

품질 확인은 `server/scripts/sample_excuses.py`(상황 3 × 레벨 1·5·10 × 말투 2 = 18개)와, 문제마다 따로 만든 점검 스크립트(같은 조건으로 5~10번 생성 + 정규식 자동 검사)로 했다.

### 1차: 프롬프트만으로 모든 것을 정함 (M3)

18개를 읽어 보니:

- 레벨 1인데 "무지개색 프린터", "비둘기가 랜선을 건드림" 같은 황당한 소재
- 실존 인물 등장: 세종대왕, 고려 광종
- **신뢰도가 85 / 45 / 1로 고정**: 범위를 줘도 매번 가운데 숫자
- 레벨 10이 "평행우주"로 쏠림 (프롬프트 예시를 따라 함)

### 2차: 신뢰도를 서버가 정함

신뢰도를 서버가 레벨별 범위에서 `random.randint`로 뽑아 넘기고, LLM은 그 점수에 어울리는 코멘트만 쓰게 했다. 그러자 새 문제가 생겼다.

- 코멘트의 절반(18개 중 9개)이 "61점짜리 핑계…"처럼 **점수를 직접 언급**
- 공손한 직장인체 핑계가 "…사옵니다"로 끝나는 **말투 섞임**

### 3차: 서버 검사 + 재시도

프롬프트 규칙을 더 적어도 확률적으로 새어 나와서, 응답을 서버가 정규식으로 검사하고 걸리면 재시도하게 했다 (점수 언급, 사극 어미 섞임, 실존 인물 목록). 18개 생성을 네 번 돌리고 정규식 점검 스크립트로 확인했다.

이 과정에서 시간여행 소재로만 10번 생성했더니 "세종대왕"이 또 나와서, 소재를 **"미래로 시간여행"**으로 바꾸고 실존 인물 목록 검사를 추가했다.

### 4차: 프롬프트 예시를 그대로 따라 하는 문제

| 레벨 | 프롬프트 예시 | 결과 |
| --- | --- | --- |
| 1 | 버스가 배차 간격보다 15분 늦게 왔다 | 5번 중 **5번** 버스 지각 |
| 5 | 앞사람이 동전 87개로 계산해서 같이 세어 드렸다 | 샘플 실행 3번 모두 편의점 동전 세기 |
| 10 | 평행우주의 내가 대신 출근한 줄 알았다 | 평행우주·양자역학·웜홀 반복 |

"예시는 참고만 하라"고 적어도 소용없었다. 그래서:

- 프롬프트에서 **장면 예시를 모두 빼고 원칙만** 남겼다 (예: 레벨 4~6 = "평범한 사건 하나 + 과하게 구체적인 디테일"). 장면 예시가 다시 들어가지 않도록 테스트로 막았다
- **소재를 서버가 고른다**: 레벨 1~3 후보 12개(교통·알람·업무·날씨·집안일…), 4~6은 여기서 "컨디션"을 빼고(과장하면 병명·응급실로 번지기 쉬움) 3개 추가, 7~9는 "동물" 추가, 10은 별도 12개

결과: 레벨 1을 10번 생성 → **8가지 소재, 버스 0번**.

### 5차: 레벨 7~9가 밋밋함

현실 소재를 받은 레벨 8이 현실 쪽으로 끌려가 **10개 중 5개가 레벨 5 수준**이었다(길 안내, 주차장 페인트 작업 등).

- 레벨 7~9에 **"과장 방법"**도 서버가 고르게 했다 (터무니없는 우연 / 비현실적인 규모 / 동물·사물의 엉뚱한 개입 / 작은 일의 연쇄)
- 기준 추가: "레벨 4~6보다 확실히 황당하고 웃음이 터질 정도"

결과: 밋밋함 **5/10 → 0/10**. 대신 "우산이 저절로 150개로 증식", "로봇청소기가 문을 잠금"처럼 **레벨 10으로 넘어간 것이 2개** 생겼다. "물건이 저절로 생기거나 늘어나는 것, 기계가 의지를 갖는 것은 레벨 10"이라는 경계를 넣자 그 유형은 사라졌지만, 다른 유형(엘리베이터가 저절로 초대형으로 바뀜, 출근 시간 안에 지구 반대편 왕복)이 여전히 10개 중 2개 나왔다. 여기서 튜닝을 마무리했다.

### 6차: 급식체 유행어

- `slang.py`에 표현·뜻·쓰임을 두고 급식체일 때 50% 확률로 하나를 넘김
- "망했다"는 뜻의 "줴줴이야~"가 레벨 1(신뢰도 높음)에도 쓰여 어색함 → 항목마다 **쓸 수 있는 레벨 범위** 추가(9~10)
- 쓰임에 예시 문장("이 핑계는 줴줴이야~")을 넣었더니 **5번 중 3번 그대로 베낌** → 쓰임을 설명("신뢰도가 낮을 때 코멘트 끝에 붙임")으로 바꿈 → 6번 모두 다른 문장
- "이딴"을 서버 검사에 넣자, 급식체 레벨 10에서 **첫 답 6개 중 4개가 "이딴"**을 써서 재시도에서도 또 걸려 **5번 중 2번 최종 실패** → 재시도할 때 "무엇을 어겼는지"를 프롬프트에 덧붙이도록 바꿈

### 배운 점

- LLM에게 "고르게 랜덤으로"를 맡기지 않는다. 랜덤은 코드가 정하고 결과만 알려준다
- 프롬프트의 예시 장면은 "참고"가 아니라 "정답"으로 받아들여진다. 원칙만 적는다
- 규칙은 프롬프트에 적어도 새어 나온다. 자주 새는 패턴은 서버에서 검사하고, 재시도할 때는 무엇이 틀렸는지 알려준다
- 샘플 한 번으로 판단하지 않는다. 같은 조건으로 여러 번 뽑고 개수로 센다

## 배포하며 겪은 문제

| 문제 | 원인 | 해결 |
| --- | --- | --- |
| 프록시 뒤에서 모든 사용자가 레이트리밋을 같이 씀 (배포 전 발견) | Render 프록시 주소가 클라이언트 IP로 보임. uvicorn `--proxy-headers`는 조작 가능한 `X-Forwarded-For` 맨 앞 값을 씀 | `X-Forwarded-For` 맨 뒤 값(프록시가 붙인 값)을 직접 읽음 |
| 비공개 저장소에서 keep-alive가 Actions 무료 시간을 넘음 (계산으로 발견) | 실행마다 1분 올림 × 10분 간격 = 월 약 4,300분 > 2,000분 | 저장소를 공개로 전환 |
| Expo Go에 "The Internet connection appears to be offline" | 서버가 아니라 앱 번들을 노트북에서 못 받음(폰을 LTE로 바꿈) | 같은 Wi-Fi 사용 또는 `--tunnel`. 노트북 없이 쓰는 건 웹 배포로 해결 |
| keep-alive 첫 실행 실패 | `SERVER_URL` secret이 등록되지 않음 (워크플로가 의도대로 에러 표시) | repository secret 등록 |
| 웹 결과 화면의 카드·버튼 색이 뒤섞임 | static 렌더링: 빌드 때 쿼리값 없이 그린 화면과 브라우저 화면이 달라짐 | 웹 출력을 SPA(`single`)로 변경 |
| `render.yaml`에 추가한 `ALLOWED_ORIGINS`가 반영되지 않음 | 서비스가 Blueprint 자동 동기화를 하지 않음 | 대시보드 Environment에 직접 추가 |
| iPhone 홈 화면 아이콘에 흰 테두리가 생길 수 있음 | 원본 이미지가 둥근 사각형 + 흰 여백 | 꽉 찬 정사각형으로 자르고 모서리를 파랑으로 채움 |

## 테스트

- 서버: pytest 62개. 실제 LLM은 부르지 않고 `_call_model`을 가짜 함수로 바꿔 파싱·재시도·에러 코드·레이트리밋·CORS·소재/점수/유행어 선택을 검증한다
- 앱: 자동 테스트 프레임워크 없이 타입체크(`tsc`)와 번들 빌드를 매 단계 확인했다. 웹은 헤드리스 Chrome으로 화면을 띄워 캡처했고, 서버 깨우기 로직은 느린 가짜 서버로 Node에서 확인했다
- 사람 확인: 단계마다 실제 폰(Expo Go)에서 완료 기준을 확인했다

## 남은 한계

- 실존 인물·비속어 검사는 목록 기반이라 모든 경우를 막지 못한다 ("개-" 접두어는 개찰구 같은 평범한 단어와 구분할 수 없어 검사하지 않음)
- 레벨 7~9는 여전히 10개 중 2개 정도 레벨 10 쪽으로 넘어간다
- Gemini 무료 티어라 사용자가 많아지면 한도에 걸릴 수 있다. 공개 서비스라면 유료 티어 전환과 약관 확인이 필요하다
- 앱스토어 배포는 하지 않았다 (Apple Developer Program 필요). 대신 웹을 홈 화면에 추가해 앱처럼 쓴다
- 기록·즐겨찾기는 기기(또는 브라우저)에만 저장되어 기기 간 동기화가 없다 (PRD 비목표)
